# ✨ Lumos Studio

**Fisioterapia com foco em Terapias Manuais**  
Zona Leste · São Paulo

### 🩺 Sobre o projeto

Site institucional do **Lumos Studio**, clínica de fisioterapia especializada em terapias manuais.  
Design clean, elegante e responsivo, focado em converter visitantes em agendamentos.

**Principais destaques:**
- Design minimalista com tipografia elegante (Cormorant Garamond + Jost)
- Seção de serviços com ícones SVG personalizados
- Apresentação das profissionais com botão direto para WhatsApp
- Depoimentos de pacientes
- Mapa interativo do Google Maps
- Totalmente responsivo (mobile-first)
